# Student Marks Calculator

A beginner-friendly Python student project that calculates a student's total marks, percentage, grade, and pass/fail result.

## Features
- Accepts a student name and number of subjects
- Validates marks from 0 to 100
- Calculates total marks and percentage
- Assigns a grade
- Displays Pass if every subject has at least 35 marks; otherwise displays Fail

## Requirements
- Python 3.8 or later
- No third-party packages required

## How to run
1. Extract the ZIP file.
2. Open a terminal or command prompt in the project folder.
3. Run:

   ```bash
   python main.py
   ```

   On some systems, use `python3 main.py`.

## Grade scale
| Percentage | Grade |
|---|---|
| 90–100 | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 50–59.99 | D |
| Below 50 | F |

This is an educational example. Adjust the grading and passing rules to match your institution's requirements.
